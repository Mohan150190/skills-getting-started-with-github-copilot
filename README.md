## AES128 Decryption Tool

This repository includes a C-based tool for decrypting data using AES-128 encryption algorithm.

### Quick Start

1. Build the tool:
   ```bash
   make
   ```

2. Decrypt hex-formatted data:
   ```bash
   ./aes_decrypt <hex_encrypted_data> <hex_key>
   ```

3. Run tests:
   ```bash
   ./test_aes.sh
   ```

See [README_AES.md](README_AES.md) for detailed documentation.
